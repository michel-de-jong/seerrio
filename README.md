# Seerr Lite

Seerr Lite is an unofficial iOS and Android client for a self-hosted [Seerr](https://github.com/seerr-team/seerr) server (3.x). Household members sign in with their Seerr account, discover and search titles, request movies or seasons, and follow those requests. People who manage requests can approve or decline them.

It is not affiliated with the Seerr project. The phone app talks only to your server and to `image.tmdb.org` for posters.

## Develop

Install dependencies and start the development server, then open the project in Expo Go:

```bash
npm install
npx expo start
```

Use `npx expo start --tunnel` when the phone is not on the same network as the computer. The localhost page is a browser preview. It keeps the session in `localStorage` because the phone keychain is unavailable there. Expo Go is only a development container. Store and preview builds are standalone native apps with their own home-screen tile; their users do not need Expo Go or an Expo account. `ios/` and `android/` are generated by Expo and are not committed.

Other checks:

```bash
npm run typecheck
npm run lint
npm test
npm run smoke
```

`npm run smoke` is read-only. Copy `.env.example` to `.env.local` and set `SEERR_URL`. Add `SEERR_EMAIL` and `SEERR_PASSWORD` only when you also want the signed-in checks. `.env.local` is gitignored and is never bundled into the app. The script does not create, approve, decline, delete, or reset anything.

## First launch

1. Enter the Seerr address, including `http://` or `https://`.
2. Sign in with the email and password of your native Seerr account.
3. Forgot password appears only when the server can send email.
4. API key sign-in is under Advanced. It acts as the admin account.

The permanent iOS bundle identifier and Android package are `io.seerrlite.app`. Native builds permit cleartext HTTP so they can reach local self-hosted servers. HTTPS is strongly preferred because HTTP exposes credentials and session cookies to the network.

## Native builds

[EAS Build](https://docs.expo.dev/build/introduction/) produces signed iOS and Android binaries. Expo remains the build framework, but neither Expo Go nor an Expo proxy is part of the installed app's runtime or Seerr traffic.

One-time project and account setup:

```bash
npx eas-cli login
npx eas-cli init
```

Create installable internal builds:

```bash
npx eas-cli build --platform all --profile preview
```

Create and submit App Store and Play Store builds:

```bash
npx eas-cli build --platform all --profile production
npx eas-cli submit --platform ios --profile production
npx eas-cli submit --platform android --profile production
```

An Apple Developer membership and App Store Connect app are required for iOS. A Google Play Console account and app are required for Android. EAS prompts for signing credentials and account-specific identifiers; they are not stored in this repository.
